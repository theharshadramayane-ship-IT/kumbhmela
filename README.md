# Kumbh Mela Management System

A Flask-based web application designed to support registration and information management for Kumbh Mela operations.

## Project Overview

The Kumbh Mela Management System provides a web interface for different registration activities. It uses Python Flask for backend functionality and SQLite for database management.

## Features

- Parking Agent Registration
- Traveller Registration
- Vehicle Registration
- Customer Registration
- Admin Dashboard
- SQLite database management
- CSV-based data handling
